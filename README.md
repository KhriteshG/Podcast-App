# Podcast-App
Project Overview

The Podcast App is a dynamic mobile application that allows users to browse, stream, and manage podcast episodes. The application focuses on smart content delivery by using device hardware and web APIs to enhance user experience. User account functionality has not yet been implemented; the current version allows open access to podcast content.
The app integrates hardware sensors such as GPS, Camera, and Microphone, along with external APIs, to provide personalized and interactive features.

# Features
Browse and stream podcast episodes
Search podcasts by category and keyword
Smart music and podcast suggestions based on location (GPS)
Voice-based search using the microphone
Profile image capture using the camera (for future account feature)
API-based podcast data retrieval
Offline-ready architecture (future enhancement)
